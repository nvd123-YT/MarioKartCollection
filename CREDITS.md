## Mario Kart recompilation projects

All game runtimes, recompilation work, setup tools and game-specific features are maintained by their respective projects:

- [Super Mario Kart Recomp](https://github.com/mpolizel/SMKSNESRecomp)
- [Mario Kart 64: Recompiled](https://github.com/sonicdcer/MarioKart64Recomp)
- [Mario Kart Super Circuit Recomp](https://github.com/mstan/MarioKartSuperCircuitRecomp)
- [DS Kart Recompiled](https://github.com/AlonsoTlol/DS-Kart-Recompiled)
- [WiiCompiled](https://github.com/patchzyy/Wiicompiled)
- [Mario Kart 7 Recompiled](https://github.com/nvd123-YT/MK7Recomp)
- [MK8-online](https://github.com/Vnnc1/MK8-online)

Each project keeps its own license, requirements, release cadence and credits. Please consult its repository for details.
