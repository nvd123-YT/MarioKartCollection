# Mario Kart Collection 0.1.0

- Fork RecompLauncher as a Mario Kart-only desktop collection.
- Bundle the eight existing Mario Kart recompilation projects.
- Fetch each game's release list directly from its original GitHub repository.
- Keep the original per-game installer, setup profile and launcher behavior.
- Rebrand the desktop interface with a dark racing palette, Archivo typography, and custom application/tray SVG artwork.
- Keep local save discovery, backups and restore; disable the upstream hosted account/cloud/community endpoints by default.
- Update the collection itself from its own GitHub Releases.
