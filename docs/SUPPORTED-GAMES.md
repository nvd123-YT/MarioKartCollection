# Supported Mario Kart projects

The collection contains these eight existing recompilation projects. Each build is downloaded directly from the project's own GitHub Releases; this table describes the platform packages currently selected by the bundled catalog, not a promise of feature completeness.

| Game | Windows x64 | macOS Apple Silicon | Linux x86-64 | Release project |
|---|---:|---:|---:|---|
| Super Mario Kart | Yes | — | — | [mpolizel/SMKSNESRecomp](https://github.com/mpolizel/SMKSNESRecomp) |
| Mario Kart 64 | Yes | Yes | Yes | [sonicdcer/MarioKart64Recomp](https://github.com/sonicdcer/MarioKart64Recomp) |
| Mario Kart: Super Circuit | Yes | — | Yes | [mstan/MarioKartSuperCircuitRecomp](https://github.com/mstan/MarioKartSuperCircuitRecomp) |
| Mario Kart DS | Yes | Beta | Beta | [AlonsoTlol/DS-Kart-Recompiled](https://github.com/AlonsoTlol/DS-Kart-Recompiled) |
| Mario Kart Wii | Yes | — | Yes | [patchzyy/Wiicompiled](https://github.com/patchzyy/Wiicompiled) |
| Mario Kart 7 | Yes | Yes | Yes | [nvd123-YT/MK7Recomp](https://github.com/nvd123-YT/MK7Recomp) |
| Mario Kart 8 Deluxe | Experimental | — | — | [Vnnc1/MK8-online](https://github.com/Vnnc1/MK8-online) |
| Mario Kart World | Early build | — | Yes | [adriadam10/mkw-recomp](https://github.com/adriadam10/mkw-recomp) |

## Important notes

- Super Mario Kart's current release selected here is Windows-only.
- Mario Kart DS's Linux and macOS packages are beta according to its project README.
- Mario Kart Wii publishes additional macOS package formats, but those aren't currently selected by this launcher's generic installer profile.
- Mario Kart 8 Deluxe and Mario Kart World are still experimental/early-stage. Expect incomplete features and compatibility issues.
- Mario Kart 7 uses this fork's existing [MK7Recomp](https://github.com/nvd123-YT/MK7Recomp) project and its setup profile.
- A project may change its asset names, platforms, prerequisites or release status at any time. The next collection update can revise the bundled asset patterns.

## Your own game files

Every game requires the game-specific dump and may require a BIOS, keys or firmware. Read the upstream project's instructions before installation. No ROMs, Nintendo system files, keys, firmware, game code or other proprietary game data are included in this repository or its releases.
